E-Commerce Sales Analyzer (Java)

Project Description

In this project, I created a Java application to analyze store sales data using Object-Oriented Programming (OOP). The goal is to calculate total sales, total profit, and profit margin, and to find which products are losing money.

Tools

Language: Java

Concepts: Object-Oriented Programming (Classes, Methods), ArrayList

IDE: Eclipse

Key Analysis Questions

-What are the total sales and total profit?

-What is the overall profit margin percentage?

-Which product categories are losing money?

Key Findings & Features

-Clean Structure: Split the code into 3 separate files (Order for data, SalesAnalyzer for calculations, and Main to run the program).

-Financial Calculations: Successfully calculated total sales, total profit, and profit margin percentage.

-Loss Detection: Found products that lose money (like Tables) to help the business fix its pricing.
